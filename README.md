> طالب بالأزهر الشريف، وأبني أدوات عربية أولًا (Arabic-first) تعمل بلا إنترنت وبلا حساب.

أكتب الكود لأن مشاكل أعرفها: مذكرة عبادات لا ترسل بياناتي لأحد، ومراقب نظام لا يكسر شريط GNOME، وخط أنابيب يحوّل كتبًا عربية PDF إلى نصوص وكلمات قابلة للتحرير. معظم عملي خاص، والعامّ منه مكتمل وموثّق.

## ما لا تراه هنا (خاصّ، لكنه الأكثر نضجًا)

- **خط أنابيب مستندات عربية**: تحويل كتب PDF إلى نص ثم إلى Word منسّق، مع طبقة OCR ومعالجة تجويد/نحو، Monorepo بـ pnpm وTypeScript في وضع strict، و ESLint يفرض حدود الطبقات المعمارية بدل أن يتركها للاتفاق.
- **تطبيق يوم الطالب**: PWA لإدارة الحفظ والمراجعة والمذاكرة، يعمل بلا شبكة وبلا حساب Google، وخيار المزامنة opt-in صريح — والبيانات الحسّاسة (عبادات، حضور، قرآن) لا تغادر الجهاز إلا إذا طلبت ذلك بنفسك. خلفية على Cloudflare Workers و D1 مع Web Push عبر VAPID.
- **حارس انحراف النشر**: فحص مجدول يقارن النسخة الحيّة بمحتوى المستودع الملتزَم، لأن دفعةً نسَت إعادة البناء تنشر نسخة قديمة بصمت — وقد كشف ذلك فعلًا.

## مبادئ التزمت بها في كل مستودع

1. **يعمل بلا إنترنت أولًا، وبالإنترنت ثانيًا.** لا ميزة أساسية تنتظر خادمًا.
2. **لا حساب لإتمام وظيفة.** التسجيل تحسين، ليس بوابة.
3. **الخصوصية بالبناء لا بالوعد.** البيانات الحسّاسة opt-in، ويُقال للمستخدم بصراحة إن الحمولة ليست مشفّرة طرفًا لطرف.
4. **العربية أساس التصميم**: اتجاه RTL من أول سطر، وخط عربي مرخّص OFL مضمّن، وأرقام هجرية بحساب أم القرى.
5. **المعمارية يفرضها الـ lint لا المراجعة البشرية.** حدود الطبقات قاعدة آلية، فالانحراف عنها يفشل البناء لا النقاش.
6. **الدفع لا ينتهي بخروج الأمر 0 على جهازي.** ينتهي عند CI أخضر على السيرفر لنفس الـ SHA.
7. **الفحص الآلي للأسرار يجب أن يقرأ النصّ لا البادئات فقط.** تسريب حقيقي حدث لأن الفحص كان يبحث عن `sk-` و`ghp_` فقط، فعدتُ قواعد الفحص ترصد كلمات المرور الصريحة ومسارات الملفات الممنوعة.
